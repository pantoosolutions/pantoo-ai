# UI Registry

Living document. Updated after every component is built. Read this before building any new
component — match existing patterns exactly before inventing new ones.

---

## How to Use

Before building any component:

1. Check if a similar component already exists here.
2. If yes — match its exact classes/styles.
3. If no — build it following rules.md and tokens.md, then add it here.

After building any component, update this file with the component name, file path, and the exact
classes/styles used.
